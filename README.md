-------- ANOTAÇÕES --------

- Na tela inicial mostra:
O nome da empresa e dois locais para inserir dados de email e senha para acessar o dashboard da empresa.

- Na tela de dashboard mostra: 
O nome do usuário, categoria e um botão para sair da conta que está logada;
A quantidade de acessos na empresa, mostrando as atividades feita pelos funcionários recentemente;
Recursos que a empresa possui mostrando o ID, a Categoria e os Status;
Um conteiner mostrando para onde o usuário quer ir (sendo "Refeitório e Escritório", "Laboratório de Pesquisa" e a "Batcaverna")

- Cada usuário possui um nível para acessar algumas áreas na empresa, 
demonstrando logo em baixo do local o nível necessário;
Caso o usuário não tiver o nível requisitado, irá aparecer uma tela de aviso 
o informando que não é possível ele acessar aquela área.

- Funcionário só consegue acessar o Escritório e o Refeitório.

- O gerente tem quase os mesmos acessos do ADM, porém ele não pode remover produto e acessar a "Barcaverna".

- O administrador ele possui botões para modificar os recursos,
podendo mudar os dados do recurso, adicionar recursos e remover recursos (o ID sendo arrumado em ordem).
